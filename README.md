# Cara Menjalankan Notebook

### Menggunakan Google Colab

1. Buka repository GitHub ini.
2. Pilih notebook yang ingin dijalankan.
3. Klik notebook yang diinginkan, kemudian buka menggunakan Google Colab.
4. Jalankan setiap sel kode secara berurutan.

### Menjalankan Secara Lokal

Clone repository:

```bash
git clone https://github.com/freezetea/data-science-2026.git
```

Masuk ke folder repository:

```bash
cd data-science-2026
```

Install library yang dibutuhkan:

```bash
pip install pandas numpy matplotlib seaborn scikit-learn scipy requests
```

Kemudian jalankan notebook menggunakan Jupyter Notebook atau Visual Studio Code.
